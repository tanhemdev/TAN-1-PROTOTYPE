## Problem

Diabetes management is reactive. Existing CGM devices surface raw glucose data but not actionable, plain-English guidance for patients and caregivers. A newly diagnosed Type 1 patient or their family has no single platform that unifies tracking, predictions, and emergency alerts in language they can act on.

## Solution

TAN-1 integrates non-invasive biosensors with a predictive AI layer. Instead of showing a glucose graph and leaving interpretation to the user, TAN-1 translates biometric data into clear, timely recommendations.

**What I did:**

- Led product vision from first principles — defined the problem space, user personas, and core value proposition
- Worked with engineers to build a **92% accuracy** risk-prediction model using biosensor data
- Designed high-fidelity **Figma mockups** mapping complete user journeys (patient → caregiver → clinician)
- Prioritized the product roadmap with data-driven insights from 30+ user interviews
- Built caregiver notification loops for real-time alerts

## Impact

- Led roadmap from **0 → 1**, from problem definition through working prototype
- Pitched to investors at UC Berkeley's BASICS Fall Pitch Day. [**Featured in Berkeley L&S News**](https://ls.berkeley.edu/news/cognitive-science-students-pitch-health-tech-ai-assistants-investors)
- Designed solutions impacting **~2,000+ potential users** across diabetes management pathways
- Integrated **3 biosensor data sources** into a unified prediction pipeline
